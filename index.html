Medicare Pro — Clinic Management System

A database-driven clinic management web application developed to support core clinic operations including patient management, appointments, medical records, prescriptions, medicine inventory, payments, and reporting.

PHP 8.2+ CakePHP 5.3 (MVC) MySQL Database HTML5 CSS3 JavaScript

System Interface Views (Screenshots)

Sanitized demo screenshots

Verified System Functionality

01 Patient Management

Patient records with search, filtering, status management, and links to related medical records.

02 Appointment Management

Appointment creation and editing, doctor assignment, and status workflow management from scheduling through completion or cancellation.

03 Electronic Medical Records

Patient-linked records for symptoms, diagnoses, treatment, vital information, visit history, and prescription information.

04 Prescription & Inventory

Prescription item management, medicine selection, quantity tracking, dispensing status, and inventory stock updates.

05 Billing & Payments

Billing records, payment methods, invoice searching, discount calculations, and payment viewing.

06 Dashboard & Reporting

Dashboard KPI information for patients, inventory, and revenue, with daily, weekly, and monthly period views.

Technical Architecture & Engineering Highlights

Medicare Pro is a fully database-driven web application built with structured MVC principles rather than static pages.

  • MVC Architecture (CakePHP): Structured separation of Controllers, Models/Entities, and CakePHP Templates.
  • Relational Database Modeling: Interconnected MySQL database schemas linking patients, medical records, prescriptions, medicines, appointments, and payments.
  • Transactional Data Updates: Automated medication inventory deduction upon prescription issuance.
  • Security & Sessions: Secure session-based user authentication and role-based interface authorization.
  • Debugging & Diagnosis: Troubleshooting of controller actions, template rendering, query performance, and system logic.

CAPSTONE WEB APPLICATION Capstone Project | UiTM | 2026

XAI Pantry — AI Meal Planner

An explainable-AI pantry tracker and meal planner designed to help users manage pantry ingredients, track expiry dates, receive personalised meal recommendations, reduce food waste, and manage shopping needs.

HTML CSS JavaScript localStorage Rule-Based Recommendation Logic Responsive Web Design

Application Interface Showcase

Five provided application views

Verified System Functionality

01Pantry Inventory Management

Manage ingredients with quantities, categories, storage locations, expiry dates, status indicators, search, filtering, editing, and deletion.

02Explainable AI Meal Recommendation

Recommend meals using pantry availability, ingredient matching, expiry considerations, dietary preferences, allergies, meal type, cuisine, and maximum cooking time.

03Explainable Recommendation Logic

Provide a human-readable explanation of why a meal was selected rather than an unexplained recommendation.

04Expiry Tracking

Track fresh, expiring-soon, and expired pantry ingredients and use expiry information in the recommendation workflow.

05Shopping List Management

Manage shopping items, mark items as completed, track progress, and support shopping-list workflows.

06Dashboard & Pantry Insights

Provide an overview of pantry inventory, expiring and expired items, recommendations, pantry utilisation, and notifications.

Technical Architecture & Engineering Highlights

XAI Pantry is a client-side web application with an explainable rule-based recommendation engine and a localStorage-based data layer.

  • Explainable Recommendation Engine: Calculates recommendation scores with pantry matching, expiry bonuses, missing-ingredient penalties, and hard filters.
  • Client-Side Data Layer: Uses localStorage to persist application data and user-specific records without a production backend database.
  • CRUD Workflows: Supports creating, editing, deleting, and managing pantry and shopping-list records.
  • Preference-Aware Filtering: Applies dietary, allergy, meal type, cuisine, and maximum cooking-time filters.
  • Responsive Design System: Uses reusable, pantry-inspired interface components with light and dark theme support.
