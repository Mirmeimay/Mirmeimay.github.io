### XAI Pantry — AI Meal Planner

An explainable AI-inspired pantry and meal-planning web application designed to help users manage pantry ingredients, track expiry dates, receive personalised meal recommendations, reduce food waste, and manage shopping needs.

**Key features:**

- Pantry inventory management
- Expiry tracking
- Meal recommendations
- Explainable recommendation logic
- Shopping list management
- Dashboard and pantry insights
- Preference-aware filtering

**Technologies / Methods:**

- HTML
- CSS
- JavaScript
- LocalStorage
- Rule-Based Recommendation Logic
- Responsive Web Design
